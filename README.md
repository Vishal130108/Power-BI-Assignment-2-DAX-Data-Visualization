# 📊 E-Commerce Sales Performance Dashboard | Power BI

## 📌 Project Overview

This project showcases the development of an interactive **Business Intelligence dashboard** using **Microsoft Power BI** and **DAX (Data Analysis Expressions)** to analyze an E-Commerce Sales dataset.

The dashboard enables users to monitor sales performance, compare actual sales against targets, analyze profitability, identify product trends, and evaluate regional order distribution through interactive visualizations and Key Performance Indicators (KPIs).

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Compare actual sales against sales targets.
- Monitor monthly sales trends.
- Identify profitable product sub-categories.
- Evaluate category-wise sales performance.
- Analyze regional order distribution.
- Create business metrics using DAX.
- Build an interactive dashboard for business decision-making.

## 📈 Dashboard Features

- 📊 Sales Target Achievement by Category
- 💰 Maximum Profit Margin by Sub-Category
- 📉 Monthly Sales Trend Analysis
- 🎯 Total Sales vs Sales Target KPI Cards
- 📦 Sales Distribution by Sub-Category (Treemap)
- 📍 Order Count Analysis by State
- 📋 Sales Performance Matrix
- 📌 Profit vs Quantity Analysis (Scatter Chart)

---

## 🔍 Key Insights

- Electronics achieved the highest sales performance.
- Furniture recorded the lowest sales achievement.
- Printers generated the highest profit margin.
- Monthly sales show a declining trend.
- Sales quantity and profitability vary across sub-categories.
- State-wise order analysis highlights regional demand.
- KPI cards provide quick comparison between actual sales and sales targets.
